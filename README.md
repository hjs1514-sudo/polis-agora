# 🏛️ 폴리스 학급회의

그리스 폴리스를 테마로 한 학급회의 웹앱입니다. 중학교 2학년 담임이 우리 반 학급회의에 쓰려고 만들었고, 다른 선생님도 내려받아 자기 학급에서 쓸 수 있게 공개합니다.

```
① 주제 공지  →  ② 아고라 광장  →  ③ 교사 채택  →  ④ 아크로폴리스 투표  →  ⑤ 신탁 판결
   (선생님)        (학생 의견·공감)     (2~4개 고르기)      (1인 1표, 도편)         (판결문 + 목소리)
```

- 학생은 **선생님이 미리 넣은 명단**(학년/반/번호/이름)과 **입장 코드**가 맞아야 들어옵니다.
- 처음 들어올 때 레고풍 시민 아바타 10종(남녀 각 5) 중 하나를 고릅니다.
- 아고라에서는 학생끼리 **이름 없이 아바타로만** 보입니다(설정에서 바꿀 수 있음). 선생님은 항상 작성자를 봅니다.
- 투표 중에는 득표가 아무에게도 보이지 않고, **신탁 판결**에서 처음 공개됩니다. 동점이면 동점 의견만으로 다시 투표합니다.
- 선생님 화면: 명단 붙여넣기, 로그인 초기화(한 학생은 한 기기만), 글쓰기 멈춤, 의견 숨기기·다듬기·별표, 참여 현황, TV 화면, 회의 기록 CSV 내려받기, 학년말 비우기.

## 먼저 체험해 보기 (설치 없음)

`Code → Download ZIP`으로 내려받아 압축을 풀고 **`dist-demo/index.html`을 더블클릭**하면 체험판이 열립니다.

- 서버 없이 그 브라우저 안에서만 돌아가고, 어디에도 저장하거나 보내지 않습니다.
- 위쪽 띠에서 **교사 보기 / 학생 보기**를 오가며 혼자서 회의 한 번을 끝까지 해 볼 수 있습니다.
- 교사 PIN `0000`, 입장 코드 `1234`, 학생은 `2학년 1반 12번 오시우`. 나머지 가상 학생 11명이 알아서 의견을 쓰고 투표합니다.

## 내 학급에서 쓰기 (Cloudflare 무료)

학생들이 각자 기기로 들어오려면 의견과 투표를 모아 줄 서버가 필요합니다. Cloudflare Pages(무료)와 D1 데이터베이스(무료)를 씁니다.

1. 이 저장소를 내 GitHub로 **Fork** 합니다(오른쪽 위 Fork 버튼).
2. [Cloudflare 대시보드](https://dash.cloudflare.com) → **Workers & Pages → 만들기 → Pages → Git에 연결** → Fork한 저장소 선택.
3. 빌드 설정
   - 프레임워크: `None` (또는 Vite)
   - 빌드 명령: `npm run build`
   - 빌드 출력 디렉터리: `dist`
4. 배포가 끝나면 **Workers & Pages → D1 → 데이터베이스 만들기**(이름 예: `polis-db`).
5. 만든 Pages 프로젝트 → **설정 → 바인딩 → 추가 → D1 데이터베이스**, 변수 이름은 꼭 **`DB`**, 데이터베이스는 방금 만든 것. 저장 후 **배포를 한 번 다시** 합니다(배포 탭 → 다시 시도).
6. `https://내프로젝트.pages.dev/#/teacher`에 들어가 **학급방 만들기**(학년·반·입장 코드·교사 PIN). 표는 처음 접속할 때 자동으로 만들어집니다.
7. 명단 탭에 번호와 이름을 붙여넣고, 학생들에게 `https://내프로젝트.pages.dev/` 주소와 입장 코드를 알려 주면 끝입니다.

> 배포 직후에는 아무나 학급방을 만들 수 있으니 **배포하자마자 선생님이 먼저** 6번을 해 두세요.

무료 한도: 30명이 3초마다 확인하므로 45분 회의 한 번에 요청 약 2만 7천 번입니다. Cloudflare 무료 한도(하루 10만 번) 안에서 하루 2~3번 회의는 넉넉합니다.

## 고치고 싶을 때

| 바꿀 것 | 파일 |
| --- | --- |
| 단계 이름, 의견 글자 수, 1인 의견 개수, 채택 개수, 금칙어, 판결문 말투 | `src/core/engine.js` |
| 아바타 그림 | `public/img/avatars/m1~m5.png, f1~f5.png` (정사각형) |
| 배경 그림 | `public/img/bg/gate·agora·acropolis·oracle.png` |
| 체험판 가상 학생과 예시 의견 | `src/api/demo.js` |
| 색과 모양 | `src/styles.css` |

```bash
npm install
npm run dev          # 실사용판 화면 (서버 없이 화면만)
npm run dev:demo     # 체험판
npm test             # 회의 규칙 시험
npm run build:all    # dist/ (실사용판) + dist-demo/ (체험판 한 파일)
```

서버 코드는 `functions/api/polis/[[path]].js` 한 파일이고, 회의 규칙은 `src/core/engine.js`를 서버와 체험판이 함께 씁니다.
